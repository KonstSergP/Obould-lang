# Fractal Flame on Obould

Порт Java-домашки `examples/fractal-flame-java` на Обольд.

## Что есть

- многопоточный рендер
- 15 вариаций
- симметрия
- логарифмическая гамма-коррекция
- сохранение результата в PNG

## Сборка

Сначала соберите компилятор в корне репозитория:

```bash
cmake -S . -B build && cmake --build build -j
```

Далее в этой директории соберите программу:

```bash
# собирает
make
# собирает и запускает один из примеров
make run
```
Исполняемый файл `.obould/fractal-flame`

## Примеры запуска

Минимальный запуск с дефолтами:

```bash
.obould/fractal-flame
```

Еще пример для проверки:

```bash
.obould/fractal-flame \
  -w 1920 -h 1080 \
  -i 100000000 \
  -t 4 \
  -o demo.png \
  -f diamond:0.58,handkerchief:0.96,spherical:0.22 \
  -ap -0.295,1.168,-0.631,-0.846,-0.765,0.059/-0.521,-0.195,-0.883,0.266,0.092,-0.873/-0.967,-0.89,0.847,-0.538,-0.921,1.003/-0.343,1.094,-0.868,0.899,-0.8,0.96/-0.547,1.126,-1.159,-0.716,-0.435,0.507\
  --seed 15 \
  -g --gamma 1.5 \
  -s 6
```

### Также несколько примеров находятся в файле `examples.txt`

### Также есть Python скрипт для интерактивной генерации красивых фракталов

```bash
python3 generator.py # генерация на пробел
```

Справка по аргументам:

```bash
.obould/fractal-flame --help
```
